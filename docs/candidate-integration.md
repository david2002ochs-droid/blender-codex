# Source snapshot

The public repository starts from the reviewed 7 November 2026 hackathon integration, local source commit `45d37b0d23ceff64e3a27c7ebe7386174057bd2c`. Its implementation includes the pinned Deepblick chat, scene lifecycle handling, public reasoning summaries, large JSONL history, Hi3D multi-view input, Blender welcome screen, and movable/resizable chat host.

Publication adds public installation/development documentation, licensing, repository hygiene, reproducible browser-test dependencies and CI. Optional developer-schema checks are separate from normal behavior tests so a fresh checkout can run the suite.

Runtime transcripts, private development snapshots, credentials, compiled host binaries and presentation files are excluded. In-flight steering remains unfinished and is not included.
